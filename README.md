# EmailToCardbase

Windows-служба для автоматической обработки карточных данных:

1. проверяет почтовый ящик и сохраняет ZIP-вложения;
2. извлекает CSV-файл из ZIP;
3. конвертирует данные в TXT нужного формата;
4. запускает `Cardimp.exe` для импорта;
5. сохраняет подробный журнал выполнения.

## Файлы

- `email_service.py` — Windows-служба и планировщик задач;
- `mail.py` — загрузка вложений из почты;
- `magnit.py` — обработка ZIP, CSV и запуск конвертера;
- `chg.py` — отдельная обработка файлов CHG;
- `convert_last12.py` — конвертация CSV в TXT;
- `convert.bat` — ручной запуск обработки MAGNIT;
- `install_service.bat` — установка службы;
- `uninstall_service.bat` — удаление службы;
- `config.example.ini` — безопасный шаблон настроек.

## Настройка

1. Скопируйте `config.example.ini` в `config.ini`.
2. Укажите адрес почты, пароль приложения и фильтры.
3. Проверьте список задач в секции `[tasks]`.
4. Запустите `install_service.bat` от имени администратора.

Файл `config.ini` не должен добавляться в Git: он содержит учетные данные.

## Обработка ZIP

Служба принимает ZIP-файлы из `attachments` и из корня рабочей папки. Перед запуском `magnit.py` вложения переносятся в корень рабочей папки.

При успешной обработке файлы перемещаются в `OLD`. При ошибке ZIP остается в рабочей папке для визуальной проверки.

## Логи

Основной лог службы находится в `logs/email_service.log`. Лог обработки MAGNIT находится в `logs/magnit_card_import.txt`.

Обработка CHG записывает отдельный лог в `logs/CHG_IMP_LOG.txt`. Обработанные файлы CHG перемещаются в папку `CHG_OLD`.

## Установка зависимостей

```bat
python -m pip install pywin32
```

`Cardimp.exe` является внешней программой и в репозиторий не включается.
